Ledger Application (Capstone 1)

This is a CLI financial ledger app built using Java.
- Allows users to record deposits and payments, view transaction history, generate reports, and search by vendor or custom parameters.
- All transactions are saved to CSV file and automatically loaded on startup

Features:
- Make Deposit
- Add payments
- View transactions
- Generate reports (Month to date, previous month, year to date, previous year, search by vendor, and custom search)
- Saves data in "transactions.csv" and loads automatically

How to run:
1. Open in IntelliJ
2. Run 'HomeScreen.java' file
3. Follow prompts to add deposits or payments
4. Select Ledger -> All Transactions to view history
5. Select Exit to save transactions to transactions.csv
